# Sitio de Christian Vega

Abre dist/index.html en tu navegador o usa Live Server desde Visual Studio Code. No requiere instalar dependencias. Publica el contenido completo de dist en un alojamiento estático.

## Páginas
- index.html: portada y prioridades.
- propuestas.html: seis compromisos.
- sobre-mi.html: formación y trayectoria.
- participa.html: contacto y formulario que prepara un correo, sin almacenar datos.

Edita el contenido directamente en cada HTML. styles.css comparte el diseño y app.js contiene el menú y el formulario. content.js conserva los datos originales como referencia; las páginas no dependen de él.

La ruta documental y la galería no se publican hasta contar con fechas, documentos y medios reales. No se muestra el casillero en esta versión: confirmar su vigencia antes de reincorporarlo. Verificar información biográfica y electoral antes de publicación.

## GitHub Pages

El sitio se publica desde dist mediante GitHub Actions al subir cambios a main. Los respaldos y las skills locales no se versionan.
